## 💡 How to use the tools

The application runs in the background. Once you open the program, a small icon appears in your system tray near the clock. Right-click this icon to see your list of available skills.

### Web engineering
The app helps you write clean code for your website projects. Select the "Web Expert" skill to generate basic page layouts. You provide the goal, and the system drafts the necessary files.

### Data tasks
Use the "Data Supremacy" skill to sort large tables or organize folders. The AI creates a plan to rename files or calculate values based on the rules you provide.

### Building connections
The "MCP Builder" skill links your AI to different online services. This allows your agent to pull information from calendars or cloud storage folders. You can manage these connections inside the main dashboard.

### Artistic creation
Select "Algorithmic Art" to generate custom visuals. The AI uses geometric rules to create images. Adjust the sliders in the menu to change the colors and shapes of your art.

## 🛡️ Privacy and safety

The application keeps your data on your machine. It only connects to the internet to perform the tasks you request. You control what information the AI shares. You can stop the application at any time by right-clicking the icon and selecting "Exit."

## 🧩 Modifying your experience

You can tweak how the agent behaves. Open the "Settings" menu from the tray icon. You can set limits for how much the AI can process at once. Use the "Self-Evolving" toggle to allow the agent to learn from your past feedback. This improves the accuracy of your results over time.

## 📋 Solving common issues

Sometimes the software might stop responding. Follow these tips to fix the problem.

*   **App won't start:** Restart your computer. This clears stuck processes from the memory.
*   **Permissions error:** Right-click the shortcut and choose "Run as administrator."
*   **Updates:** We release updates to fix bugs and add new skills. Check the download page every month for a newer version.
*   **High CPU usage:** If the computer runs slowly, open the "Settings" menu and reduce the "Processing Speed" slider to lower the strain on your hardware.
